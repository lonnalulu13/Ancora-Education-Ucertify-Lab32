# Viewing the Application, Security, and System Logs

Logs are records of events that occur on a computer system. They are used to track system activity, user activity, and security-related events. Viewing the application, security, and system logs is a process of examining the log files stored on a computer system to identify any security issues or errors.

## Objective of the Lab
This lab session will demonstrate the steps involved in viewing the application, security, and system logs. Upon completion of this lab, you will be able to: 
* Understand the different types of log files and their purpose.
* Examine the application, security, and system logs.
* Access the log files stored on a computer system.

Lab/Machine environment is the Windows virtual machine.
## PART A: Opening the Event Viewer
Open the vent Viewer window.

The Event Viewer application allows you to view various log types, including application, security, and system logs. These logs can be archived for later review and can be used to spot network trends and provide data for creating baselines.
### STEP 1
From the taskbar, click the search icon. 
### STEP 2 
Type event viewer and click Event Viewer.
## PART B: Viewing the Logs
Navigate to Windows Logs and examine Application, Security, and System logs. 

Application, security, and system logs provide a detailed record of events and activities occurring on a Windows system. It helps users to diagnose problems, track application or system issues, and identify security-related events. By reviewing these logs, users can gain insights into the operation and health of their system, as well as address any potential issues or security concerns that may arise
### STEP 1
From the left pane, expand Windows Logs.
### STEP 2
Click Application and review the logs visible in the middle pane.
### STEP 3
Click Security and review the logs visible in the middle pane.
### STEP 4
Click System and review the logs visible in the middle pane.
## PART C: Saving the Logs
Right-click System and select the Save All Events As option. Type the file name as eventlogs and save it in the Documents folder.
### STEP 1
From the left pane, right-click System and select Save All Events As.
### STEP 2
Type File name as eventlogs, verify that the file is getting saved in the Documents folder, and then click Save to save the file.
### STEP 3
At the Display Information prompt, click OK.
### STEP 4 
Close all windows.
